# Installation

## Community plugins

[Open Bases Chart Views in the community plugin directory](https://community.obsidian.md/plugins/bases-chart-views), install the plugin, and enable it.

You can also search for **Bases Chart Views** in **Settings → Community plugins → Browse** inside Obsidian.

The plugin requires **Obsidian 1.12.0 or later**. Enable the **Bases** core plugin before creating a chart view. Use a current Obsidian version for the latest native property and formula editing support.

## BRAT

If you use [BRAT](https://github.com/TfTHacker/obsidian42-brat) to manage plugins:

1. Install and enable BRAT.
2. In BRAT settings, choose **Add Beta Plugin**.
3. Enter `https://github.com/haiqiang-zhang/obsidian-bases-charts`.
4. Choose **Add Plugin**.
5. Enable **Bases Chart Views** in **Settings → Community plugins**.

BRAT installs published plugin releases. It does not automatically build unpublished commits from the development branch.

## Confirm the installation

Open a Base and add a view. The plugin's chart view types should appear in the view picker. Choose one, then select its X and Y properties to render your data.

[Create your first chart →](./overview#your-first-chart)

## AI Chart setup

AI Chart uses [Claudian](https://github.com/YishenTu/claudian) to create its saved chart configuration. Install Claudian and complete its own setup before following the [AI Chart guide](./ai-charts).

## Release availability

These docs cover version **1.0.0**. See [GitHub releases](https://github.com/haiqiang-zhang/obsidian-bases-charts/releases) for subsequent changes.
