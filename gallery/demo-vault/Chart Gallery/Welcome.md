# Chart Gallery

A fictional studio's quarter, designed to show how Bases Chart Views works with ordinary Markdown properties. All data is synthetic.

## Explore the views

- [[01 Trend.base|Weekly momentum]] - date grouping and colored workstreams.
- [[02 Workstreams.base|Projects by workstream]] - grouped bars and multiple measures.
- [[03 Capacity.base|A season of progress]] - stacked area totals.
- [[04 Focus mix.base|Where the time goes]] - a proportional overview.
- [[05 Skills.base|A balanced practice]] - two radar profiles across six capabilities.
- [[06 Effort and impact.base|Effort & impact]] - 32 individual initiatives.
- [[10 AI insights.base|Focus rhythm]] - a saved ECharts heatmap in an AI Chart view.

## First-time setup

Install and enable Bases Chart Views. Copy this entire Chart Gallery folder into a vault. Keep its folder name so the Base filters continue to find the sample notes.

Set the Completed property type to Date & time and Effort to Number in Obsidian if these types are not detected automatically. Hours, Deliverables, Impact, Current, Target, Week, and Sequence are Number properties. No vault settings are included or overwritten.

The AI Chart example also requires the plugin's normal Claudian skill setup. It renders a saved configuration; it does not query the session notes live.

These examples use the current development version of Bases Chart Views. Some controls and chart types may not be available in an older community release.
